# 🏙️ Chandigarh Adda (chandigarhadda.com)

**Chandigarh’s Premier City Guide & Lifestyle Platform**  
*Your trusted companion for everything happening across the Tricity of Chandigarh, Mohali, and Panchkula.*

---

## 🌟 What Chandigarh Adda Covers
1. **Events & What’s On**: Concerts, comedy shows, festivals, exhibitions, sporting events, and nightlife.
2. **Food & Dining**: Curated café trails, restaurant reviews, Sector 26/7 microbreweries, Phase 3B2 food street, and dhaba classics.
3. **City Guides**: Iconic heritage spots (Sukhna Lake, Rock Garden, Rose Garden, Capitol Complex), markets, parks, shopping districts, and sector breakdowns.
4. **Lifestyle & Wellness**: Running clubs at Sukhna, cycling routes, boutique fashion, wellness retreats, and city culture.
5. **Local Business & Startups**: Spotlights on homegrown brands, entrepreneurs, and innovation hubs shaping Mohali IT Park and Tricity.
6. **Travel & Weekend Escapes**: Day trips and weekend getaways (Kasauli, Chail, Shimla, Morni Hills, Barog, Timber Trail).
7. **News & City Updates**: Tricity metro updates, civic news, infrastructure developments, and local stories that matter.

---

## 🚀 Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite
- **Styling**: Tailwind CSS + Custom Typography
- **Icons**: Lucide React + Custom Brand SVGs
- **Interactive Features**:
  - Live Tricity Weather, AQI, and Weekend Vibe Ticker
  - Tricity Zone Filtering (All, Chandigarh, Mohali, Panchkula, Escapes)
  - Search bar with live keyword and sector matching
  - Interactive In-depth Reader Modal with Google Maps directions & RSVP links
  - Personal Wishlist / Bookmarks Drawer with LocalStorage persistence
  - Business & Event Submission Portal for local organizers and entrepreneurs
  - Direct integration with Instagram (`@chandigarhadda`) and Twitter/X (`@chandigarhadda`)
  - Newsletter subscription capture for weekly drops

## 🛠️ Getting Started Locally

```bash
# Navigate to the project directory
cd chandigarh-adda

# Install dependencies (already completed)
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` to explore the platform.

---

## 🌐 Deploying to Production (chandigarhadda.com)
You can deploy this application with one click to:
- **Vercel**: `npx vercel`
- **Netlify**: `npx netlify deploy`
- Or simply connect your GitHub repository to Vercel/Netlify and point your custom domain **`chandigarhadda.com`**!
